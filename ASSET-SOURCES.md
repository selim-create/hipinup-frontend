# Hipinup mockup asset provenance

The v3 `hipinup-wordmark.png` is an original AI-generated wordmark, created for this owner-requested redesign and used unmodified. The brief specifies ink, blue `#20b1ea` and yellow `#fff100`; raster generation approximates the requested colors. Exact primary UI colors are defined separately in CSS. The simple favicon uses those exact colors and a typographic monogram. Advertising samples are HTML/CSS typesetting and abstract geometry for a Hip Creative house campaign.

All photographs were retrieved from the existing Hipinup WordPress site for the owner-requested design prototype. Original publication dates and URL paths are preserved. Display headlines are editorial mockup variants. Reassess image rights and original content before launch.
